# Cavendish Family Mediation

Enterprise, FMC-accredited UK Family Mediation platform for Derbyshire, Nottinghamshire, and South Yorkshire. Part of the Jason Mediation network portfolio.

## Key Features

- **Accredited MIAM & Mediation Services**: Court-accredited FMCA mediators covering Child Arrangements, Financial Settlements, and Clean Break agreements.
- **Deep Statutory Context & Anti-Doorway Compliance**: Localized procedural court pathways, Family Procedure Rules (FPR Part 3), and Ministry of Justice Mediation Voucher Scheme integration.
- **Full Schema.org Integration**: Rich LD+JSON Structured Data (`LegalService`, `BreadcrumbList`, `FAQPage`, `Article`, `LocalBusiness`).
- **AEO / GEO Optimized**: Markdown-based `llms.txt`, XML sitemaps, and robots configuration for next-generation search engine indexing.
- **Strict Accessibility & UX**: Call action buttons with single-source-of-truth phone integration, zero unicode emojis, and responsive design across desktop, tablet, and mobile.

## Development & Deployment

```bash
# Install dependencies
pnpm install

# Run development server
pnpm dev

# Build for production
pnpm build
```

## Production Deployment

This project is configured for direct zero-config deployment on Vercel:

```bash
vercel --prod
```
